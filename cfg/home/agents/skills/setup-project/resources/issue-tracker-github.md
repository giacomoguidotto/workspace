# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues. Use `gh` for issue and pull-request operations and infer the repository from its Git remote.

Record whether pull requests are a request surface. Default to `no`; when enabled, route contributor PRs through the same triage roles as issues.

When another skill says to publish or fetch a ticket, use the corresponding `gh issue` operation. Wayfinding maps use one labelled map issue, linked child issues, native dependency edges when available, and `wayfinder:<type>` labels.
