# Issue tracker: GitLab

Issues and PRDs for this repository live in GitLab Issues. Use `glab` for issue and merge-request operations and infer the project from its Git remote.

Record whether merge requests are a request surface. Default to `no`; when enabled, route contributor merge requests through the same triage roles as issues.

When another skill says to publish or fetch a ticket, use the corresponding `glab issue` operation. Wayfinding maps use one labelled map issue, child issues, native blocking links where available, and `wayfinder:<type>` labels.
