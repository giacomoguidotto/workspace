# Issue tracker: Local Markdown

Issues and specs live under `.scratch/<effort>/`. Use `spec.md` for the effort specification and one numbered file under `issues/` for each ticket. Record type and status near the top of each ticket and append conversation under `## Comments`.

Wayfinding uses `map.md`, child ticket files, and explicit `Blocked by` references. Claim and resolve tickets by updating their status without combining tickets into one file.
