# Triage Labels

| Role | Default label | Meaning |
| --- | --- | --- |
| needs triage | `needs-triage` | Maintainer evaluation is required. |
| needs info | `needs-info` | Reporter information is required. |
| ready for agent | `ready-for-agent` | Fully specified autonomous work. |
| ready for human | `ready-for-human` | Human implementation is required. |
| will not fix | `wontfix` | The request will not be actioned. |

Keep these defaults unless the repository's confirmed convention maps a role to an existing label.
